# Bharat Pawar - DSA Website  

🚀 **Live Demo**: [bharatpawar-dsa.netlify.app](https://bharatpawar-dsa.netlify.app/)  

## 📌 About This Project  
This is a web-based platform to explore **Data Structures and Algorithms (DSA)**, built using **HTML, CSS, JavaScript, and React**. It covers various DSA concepts, problem-solving techniques, and coding practice.  

## ⚡ Features  
✅ Interactive UI for better learning experience  
✅ Covers multiple DSA topics with explanations  
✅ Code snippets for quick reference  
✅ Responsive design for all devices  

## 🛠 Tech Stack  
- **Frontend**: HTML, CSS, JavaScript, React  
- **Deployment**: Netlify
